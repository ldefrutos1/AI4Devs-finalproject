# Revisiones de software (archivo)

Informes puntuales de auditoría y evaluación (abril–junio 2026): snapshots del proyecto en una fecha concreta, no documentación normativa. Algunos incluyen notas **CORREGIDO** posteriores; el cuerpo del informe puede seguir reflejando el alcance o las limitaciones del momento (p. ej. entrega parcial sin Mongo, CI aún no desplegado).

Para el **estado actual** del producto y la calidad en CI, usar [backlog.md](../backlog/backlog.md), [readme.md](../../readme.md) y [devsecops-ci.md](../engineering/devsecops-ci.md).
